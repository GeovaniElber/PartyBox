# PartyBox — Documentação

## Sobre o projeto
O PartyBox é uma plataforma para gestão de temas, reservas e alugueres, permitindo organizar os processos de atendimento, devolução e controlo administrativo.

## Tecnologias
- React
- JavaScript
- Node.js
- MySQL
- Git e GitHub
