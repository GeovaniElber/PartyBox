
# 02 — Requisitos do Sistema

## 2.1. Requisitos Funcionais

### Cliente
01 — Permitir o registo e autenticação.
02 — Consultar os temas disponíveis.
03 — Consultar a disponibilidade dos temas.
04 — Efetuar reservas.
05 — Consultar o histórico de reservas.
06 — Consultar informações sobre multas.

### Atendente
07 — Registar e gerir clientes.
08 — Gerir reservas.
09 — Registar alugueres e devoluções.
10 — Realizar averiguações.
11 — Registar multas e pagamentos.

### Administrador
12 — Gerir temas.
13 — Gerir atendentes.
14 — Consultar dashboard e faturação.

## 2.2. Requisitos Não Funcionais

— A aplicação deve possuir uma interface simples e intuitiva.
— O sistema deve garantir a segurança dos dados.
— O acesso deve respeitar os níveis de permissão dos utilizadores.
— A aplicação deve permitir comunicação entre frontend e backend através de API.
— A base de dados deve garantir a integridade e consistência da informação.
— O sistema deve ser desenvolvido para utilização através de navegadores Web.

## 2.3. Estado
Requisitos iniciais identificados. Sujeitos a atualização durante o desenvolvimento.
