
# 01 — Descrição Geral do Projeto

## 1.1. Identificação
**Nome:** PartyBox  
**Tipo:** Plataforma Web de Gestão de Reservas e Alugueres.

## 1.2. Descrição
O PartyBox é uma plataforma destinada à gestão de temas, reservas e alugueres, permitindo centralizar os processos de atendimento, acompanhamento de clientes, controlo de disponibilidade e gestão administrativa.

## 1.3. Objetivo
Desenvolver uma solução que facilite a gestão operacional, reduza processos manuais e permita um melhor acompanhamento das reservas e dos alugueres.

## 1.5. Principais funcionalidades
- Registo e autenticação de utilizadores.
- Consulta de temas e disponibilidade.
- Gestão de reservas.
- Gestão de alugueres e devoluções.
- Gestão de clientes e atendentes.
- Registo e controlo de multas.
- Dashboard administrativo.

## 1.6. Âmbito
A plataforma será desenvolvida como uma aplicação Web, com frontend, backend e base de dados centralizada.

## 1.7. Estado do projeto
Em desenvolvimento.
